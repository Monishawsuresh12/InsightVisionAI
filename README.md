# 🧠 Gemini Vision Chat App

An **AI-powered Vision Chat Application** that allows users to interact with images using natural language. Built using **Google Gemini API** and **Streamlit**, this app demonstrates the power of **Generative AI + Computer Vision**.

---

## 🚀 Features

- 🖼️ Upload one or multiple images
- 💬 Chat with images like ChatGPT
- 🔍 Detect objects in images
- 🧾 Extract text (OCR)
- 🧠 Detailed image description
- 🗂️ Conversation history (session memory)
- ⚡ Quick prompt buttons
- 🎯 Clean and interactive UI

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API (Generative AI)
- Pillow (Image Processing)
